视频旋转 v11.2（全屏自适应版）
适用：Safari + Userscripts 扩展。YouTube / Bilibili / 任意网页视频

════════════════════════════════
一、控制栏里三个小图标
════════════════════════════════
位置：YouTube 齿轮「设置」按钮的左边；B 站控制栏右侧。

     ⟳    ⚙    ⛶
   旋转   设置   全屏

· ⟳  点一下转 90°，按住 Shift 点反向转。旋转后图标会高亮。
· ⚙  点开抽屉调参数 —— 不用时窗口上不占地方，点页面别处自动收起。
· ⛶  全屏 / 退出全屏。

【全屏】三个图标会自动搬到屏幕**右下角**常驻（和播放器控制栏同侧），
位置正好抬高一截避开 YouTube 自己的控制栏，鼠标一动控制栏升起
也不会互相压住；抽屉从这组按钮上方弹出。

二、v11 修好了什么（重点）
════════════════════════════════
以前「全屏后要调很多参数才勉强正常」的根因：

  全屏时脚本把「显示区」认成了页面里的播放器小框（1080×607），
  而不是整块屏幕（1080×1920）—— 于是算出来的画面只有应有尺寸的
  1/3，要靠手动放大到 300% 才能填满，还得手动上下移动把它挪到屏幕
  中间。

v11 的改法：
· 全屏时（含 Safari 的「原生视频全屏」）「显示区」一律 = 整块屏幕。
· 「按比例」的选项改成**裁切**，不再是拉伸 —— 4:3 / 1:1 / 9:16
  不会再出现画面被压扁变形。
· 新增「一键铺满」：自动选好角度 + 铺满 + 缩放回 100% + 偏移归零。
· 新增「范围」选择：自动 / 播放器 / 整屏。
· 抽屉底部多了一行实时状态（视频比例、显示区、缩放、裁切），
  万一还是不对，把这行字发我就能立刻定位。

★ 你的用法（竖屏 1080×1920）：
  窗口模式 → 什么都不用调（默认 Auto，跟以前一样）
  全屏     → 点一下 ⟳ 转 90° 就正好铺满整块竖屏，不用再调别的。
             想更省事就点 ⚙ → 「一键铺满」。

三、抽屉里有什么
════════════════════════════════
  画面
  角度   [0°] [90°] [180°] [270°]   ← 直接点角度，不用一次次转
  比例   [Auto][Fill][16:9][4:3][1:1][9:16]
  范围   [自动][播放器][整屏]
  缩放   −   315%   +                ← 百分比按钮点一下回 100%
         ▬▬▬▬▬▬▬▬▬▬▬▬●             ← 长条独占整行：点哪就多大
  快选   [50%][75%][100%][125%][150%][200%][315%][400%]
  位置   ↑  ↓  ←  →   [对中]
         [ 一键铺满 ]  [ 全部复位 ]
         ───────────────────────
         视频 16:9（Auto 框）· 范围 1080×1920 全屏 · 缩放 100%

缩放（v11.3：**点哪就多大**，一次到位，不用再点加号一点点加）：
  · 长条      长条独占了整行（更宽更好点）—— 点长条上任意位置，缩放立刻
              就是那个大小；按住拖动跟手。想 315% 就直接点在 315% 那儿。
              （这是最快的方式，推荐）
  · 快选档位  一下跳到 50 / 75 / 100 / 125 / 150 / 200 / 315 / 400%，
              当前档位高亮
  · − / +     点一下 5%；离 100% 越远步子越大（最大 28%）
  · 长按 −/+  按住不放：240ms 后开始连调 —— 按住 1 秒约 100% → 300%，
              松手即停（不会像以前那样被"掐断"）
  · 滚轮      鼠标停在缩放行或长条上滚：默认每格 ±10%；
              ⇧ + 滚轮 = 细调 2%；⌥ + 滚轮 = 粗调 50%
  · 百分比数字 点一下回到 100%

比例说明（v11：都是「裁切」，不会变形）：
  Auto   自适应：整幅画面完整可见，尽量大（默认，推荐）
  Fill   铺满：不留黑边，四周多出来的裁掉
  16:9 / 4:3 / 1:1 / 9:16
         把画面裁成该比例并尽量放大（不是压扁）
         例：16:9 的视频选 9:16 → 取中间一条竖的画面填满

范围说明：
  自动   全屏时用整块屏幕，窗口时用播放器框（平时就用这个）
  播放器 强制按播放器框算
  整屏   强制按整块屏幕算 —— 窗口模式下也能让画面铺满屏幕

四、快捷键
════════════════════════════════
  Option + R          顺转 90°
  Option + Shift + R  反转 90°
  Option + 0          全部复位（0° / Auto / 100%）
  Option + = / -      放大 / 缩小（步长自适应；按住键盘会连发，很快）
  Option + Shift + = / -   一次跨 50%（快速逼近目标）
  f                   全屏 / 退出全屏（与 YouTube 一致）

════════════════════════════════
五、没反应怎么办（按顺序）
════════════════════════════════
1. 完全退出 Safari（Command + Q）再打开 —— 改了脚本必须这样
   才能让扩展重新读取，只刷新页面不够。
2. 页面 Command + R 刷新。
3. 页面出现「视频旋转已就绪：⟳ 旋转 · ⚙ 调比例」的提示 = 脚本在跑。
   没有这行提示 = 扩展没加载脚本：地址栏左边「大小 / AA」→ 扩展 →
   Userscripts → 改成「总是允许」→ 刷新。

注意：v11 换了设置存储空间，以前手动调出来的那套参数
（16:9 + 90° + 315%）已经作废，不再生效 —— 这是故意的，因为那套
参数本身就是在补偿 bug，现在不需要了。
